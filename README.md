Repository for class graphics projects.\
The projects use GLUT (deprecated) and OpenImageIO (OIIO).\
\
The starter folders contains code that when compiled, creates an executable that displays a blank canvas when ran.\
Currently, the starter code works on MacOS and Linux, however project code utilizing OIIO does not work on MacOS.\
\
Project 1 can load an image (3 or 4 channels) using command line inputs and write that image to JPEG\
More functionality will be added.
